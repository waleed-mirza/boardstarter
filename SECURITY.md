# Security

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/waleed-mirza/boardstarter/security/advisories/new) on this repository.

Please include what you found, where it lives, and how to reproduce it. Give the maintainers time to fix it before any public write-up.

This project uses Supabase row-level security, signed webhooks, and server-only secrets. Do not open a public issue for a leaked key, an auth bypass, or a payment-webhook flaw.
